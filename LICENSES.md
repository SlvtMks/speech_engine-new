## Модели машинного обучения

### 1. STT: Systran/faster-whisper-large-v3

- **Тип:** Speech-to-Text модель
- **Источник:** HuggingFace Model Hub
- **URL:** https://huggingface.co/Systran/faster-whisper-large-v3
- **Лицензия:** Открытая модель (уточнить на странице модели)
- **Языки:** Русский, английский и другие
- **Использование:** Распознавание речи в текст

**Примечание:** Модель загружается автоматически при первом использовании через `faster-whisper`. Лицензию модели можно проверить на странице HuggingFace.

---

### 2. TTS (RU): Silero TTS

- **Тип:** Text-to-Speech модель для русского языка
- **Источник:** torch.hub (snakers4/silero-models)
- **URL:** https://github.com/snakers4/silero-models
- **Лицензия:** **MIT License**
- **Язык:** Русский
- **Голоса:** aidar, baya, kseniya, xenia, eugene, random
- **Использование:** Синтез речи из русского текста

**Лицензия MIT:** Полностью открытая, разрешает коммерческое использование.

**Модель загружается через:**
```python
torch.hub.load("snakers4/silero-models", "silero_tts", language="ru", speaker="v3_1_ru")
```

---

### 3. TTS (EN): tts_models/en/ljspeech/tacotron2-DDC

- **Тип:** Text-to-Speech модель для английского языка
- **Источник:** Coqui TTS Model Repository
- **Лицензия:** **Apache License 2.0**
- **Язык:** Английский
- **Использование:** Синтез речи из английского текста

**Apache 2.0:** Открытая лицензия, разрешающая коммерческое использование.

**Модель загружается автоматически через Coqui TTS:**
```python
TTS(model_name="tts_models/en/ljspeech/tacotron2-DDC")
```

## Внешние утилиты

### ffmpeg

- **Тип:** Внешняя утилита (не Python-пакет)
- **Лицензия:** **GPL/LGPL** (в зависимости от сборки)
- **Источник:** https://ffmpeg.org/
- **Назначение:** Обработка аудио форматов
- **Использование:** Используется через `pydub` для конвертации аудио

**Примечание:** `ffmpeg` устанавливается отдельно как системная утилита и не входит в Python-зависимости. Используется только как внешний инструмент через `pydub`.

## Проверка лицензий

### Для заказчика

Все компоненты имеют открытые лицензии, разрешающие коммерческое использование:

1. **Прикладной код** — MIT (полностью самописный)
2. **Библиотеки** — MIT, MPL-2.0, BSD, Apache 2.0 (все открытые)
3. **Модели** — MIT, Apache 2.0, открытые модели HuggingFace

### Рекомендации

1. Проверить лицензию модели `Systran/faster-whisper-large-v3` на странице HuggingFace: https://huggingface.co/Systran/faster-whisper-large-v3
2. Убедиться, что используемая сборка `ffmpeg` имеет подходящую лицензию (рекомендуется LGPL-сборка)
3. При необходимости можно заменить `ffmpeg` на альтернативу с более подходящей лицензией
